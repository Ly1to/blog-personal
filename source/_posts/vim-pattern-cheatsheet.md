# Vim 搜索与正则：一页速查

> 只讲入门够用的部分：一个前缀、四张表、十个片段、四个坑。进阶方向列在最后，指路不展开。
>
> 环境：Vim 9.2 / Neovim（同一套 NFA 正则引擎；文中标 ⚠️ 的项仅 Vim 支持）。

---

## 0. 先记一件事：加 `\v`

Vim 默认的正则语法叫 "magic"，元字符要**加反斜杠**才生效，反直觉：

```vim
foo\|bar       " 默认：这样才是"或"
foo\+          " 默认：这样才是"一次以上"
\(foo\)\?      " 默认：这样才是可选分组
```

在模式最前面加 `\v`（very magic）之后，就接近 PCRE / JS 的习惯了：

```vim
\v(foo|bar)+   " 分组、或、量词全部直写
```

**入门只需要记住：模式一律用 `\v` 开头，其余照着下面四张表查。**

四种"魔法等级"：`\v` 最魔法 → `\m` 默认 → `\M` 少魔法 → `\V` 只保留 `\` 有含义（写死字符串时很有用）。

## 1. 字符类

```vim
\d \D    数字 / 非数字          \w \W    词字符 / 非词字符
\s \S    空白 / 非空白          \a \A    字母 / 非字母
\l \L    小写 / 非小写          \u \U    大写 / 非大写
\.       字面点                  \*       字面星号
```

方括号与 POSIX 类照常用：`[abc]`、`[^abc]`、`[a-z]`、`[[:digit:]]`、`[[:space:]]`、`[[:alpha:]]`。

## 2. 量词

```vim
*        0..n（贪婪）           {-}      0..n（非贪婪）
+        1..n                    ?        0..1
{n,m}    n..m                    {-n,m}   n..m，非贪婪
{n} {n,} {,m}
```

`\v` 下**直写花括号**：`\v<.{-}>` 匹配 `<a>`。写成 `\{-}` 反而变成字面 `{`，是新手最常踩的坑。

## 3. 分组、或、锚点

```vim
(...)      捕获组，替换里用 \1 … \9 引用
|          或（\v 下直接写竖线，默认模式要写 \|）
^  $       行首 / 行尾
<...>      词边界（\v 下直接写）；\< 反而是字面 '<'
\zs \ze    匹配的真正起点 / 终点
```

`\zs` 是 Vim 最好用的东西：让"用来定位的上下文"不被替换掉。

```vim
\v\$\zs\w+          " 定位 "$var"，只选中 var
```

## 4. 搜索命令与开关

| 命令 | 作用 |
|---|---|
| `/pat`、`?pat` | 向下 / 向上搜索 |
| `n`、`N` | 重复上一次搜索 |
| `*`、`#` | 搜光标下的**整词**（`g*` / `g#` 则不要求整词） |
| `q/` | 打开搜索历史，可编辑后回车重放 |
| `/pat/e` | 光标落在匹配**末尾**而不是开头 |
| `:noh` | 清掉高亮 |

```vim
set hlsearch incsearch ignorecase smartcase
```

`smartcase`：全小写时忽略大小写，一旦输入了大写就精确匹配。也可以临时用 `\c` / `\C` 强制。

## 5. 替换

```vim
:[range]s/pat/rep/[flags]
```

- 范围：`%` 全文、`'<,'>` 可视选区、`5,20` 行号
- flags：`g` 全行所有、`c` 逐个确认、`e` 不报"未找到"、`n` 只计数
- 替换串：`&` 整个匹配、`\1`–`\9` 分组、`~` 上一次的替换串
- 模式留空 = 复用上次搜索：`:%s//new/g`

## 6. 十个够用的片段

```vim
:%s/\s\+$//e                  " 去行尾空白
:g/^$/d                       " 删空行
:g!/^#/d                      " 删掉所有非注释行
:%s/\v(\w+), (\w+)/\2 \1/     " 交换两列
:%s/\v"([^"]*)"//g            " 删掉所有双引号字符串
:'<,'>s/\v\s+//g              " 选区内去空格
\v<(\w+)\s+\1>                " 找重复词（the the）
\v^(\w+)\s*\=\s*(.*)$         " 拆 ini 式 key = value（= 要转义）
:%s/\v(\d+)/\=submatch(1)*2/g " 数字翻倍（\= 表达式替换）
:%s/\v^\s*\zs.*//              " 只清内容，缩进保留
```

## 7. 四个必知的坑

1. **非贪婪**：`\v` 下写 `{-}`，不要写 `\{-}`。
2. **`\v` 之下等号是量词**：`=` 表示"0 或 1 次"，匹配字面等号必须写 `\=`（`~` 同理，它表示上次的替换串）。
3. **量词 + 回顾断言必须加组**：`\v(\d+)@<=x` 可以，`\v\d+@<=x` 直接报 `E871`。
4. **替换串里的换行**：`\r` 是断行（拆成两行），`\n` 是插入 NUL 字节——想换行别写 `\n`。

## 8. 进阶方向（此处不展开，只指路）

| 方向 | 关键词 | 手册 |
|---|---|---|
| 跨行匹配整段文本 | `\_s` `\_.` `\_[]`，模式里的 `\n` | `:h /\_` |
| 零宽断言 | `@=` `@!` `@<=` `@<!`、`\zs` `\ze` | `:h /\@=` |
| 非捕获组 / 可选序列 | `%(...)`、`%[abc]` | `:h /\%(` |
| 按编码指定字符 | `\%d123` `\%x2a` `\%u20ac` | `:h /\%d` |
| 替换里做变换 | `\u \U \l \L \e`、`\=submatch()` `\=printf()` | `:h sub-replace-special` |
| 批量重构 | `:g` / `:v`、`:argdo` `:bufdo` `:cdo` | `:h :g` `:h :cdo` |
| 项目内搜索 | `:vimgrep /pat/gj **/*` + `:copen` | `:h :vimgrep` |
| 性能 | 回顾断言很慢、NFA 引擎、⚠️Vim `\%#=1` 切回旧引擎 | `:h regexp-engine` |

总入口：`:h magic`、`:h pattern`。

---

> 一句话总结：**`\v` 开头，`\d\w\s` 打底，`\zs` 定边界，`\=submatch()` 收尾。**
